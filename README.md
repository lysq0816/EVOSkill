# EVOSkill：关键词预警资料持续迭代

本项目把关键词预警从“逐条 BadCase 修改提示词”升级为可审计的资料迭代闭环：

```text
模型跑测
  → BadCase 提取
  → 失败归因
  → Knowledge Gap 聚类
  → 候选资料
  → 人工审核
  → 回归跑测
```

第一阶段只生成候选资料，不会自动修改正式提示词或 `knowledge/` 中的资料。

## 安全约定

- `data/`、`output/`、Excel/CSV 文件和 `.env` 默认不会提交到 Git。
- 代码中不保存 App ID、Key ID 或其他鉴权信息。
- 真实会话数据只保留在本地；推送前应再次检查 `git status` 与暂存内容。
